## 워크스페이스 지도

```
Artel (루트, 본문에 Team Base Rule)
├─ 회의록 ─ 🗄 회의록                45행
├─ 🗄 문서 (linked view)
├─ 개인 페이지
│   ├─ 🗄 개인 정리용 페이지            23행
│   └─ GC                          데모 게임 기획 초안 3편
├─ 멘토링 ─ 🗄 질문                  10행
├─ 개발 문서
│   ├─ 🗄 (linked view)
│   └─ content_map — 씬·화면·기능 스키마 설계
├─ 개발 스탠드 업 ─ 🗄 개발 스탠드 업     95행
├─ 팀원 정보                         개인정보 포함
├─ 🗄 (제목 없는 linked view)
├─ 이동 경로 (삭제 X)                 리다이렉트 stub. 지우지 말 것
│   └─ 문서
│       ├─ 🗄 문서                   29행
│       │   ├─ (행) API 명세          → 🗄 API 명세서       168행
│       │   └─ (행) Artel 기능 명세서   → 🗄 Artel 기능 명세서  30행
│       └─ 🗄 설계 문서               integration 미연결
└─ 중간 발표 대비 3주 스프린트 계획 (8/18~9/7)
```

가장 중요한 구조적 사실 하나. **`API 명세서` 와 `Artel 기능 명세서` 는 `이동 경로
(삭제 X)` → `문서` 페이지 → `문서` database 의 행 안에 들어 있다.** 루트에서
눈으로 따라 내려가서는 못 찾는다. 이 index 를 거치거나 ID 로 직접 간다.

## 전역 함정

1. **이름이 겹친다.** `API 명세서` vs `API 명세서 (1)`, `할 일` 두 개, 페이지
   `문서` vs database `문서`, 페이지 `API 명세` vs database `API 명세서`.
   이름이 아니라 ID 로 지목한다.
2. **linked view 는 API 로 못 푼다.** UI 에서는 database 로 보이지만 API 는
   `400 does not contain any data sources` 를 낸다. 위 표의 진짜 ID 로 간다.
3. **select 값에 따옴표가 섞여 있다.** `"대체됨"`, `"Hermes 보완"`,
   `"할 일 있음"` 이 별도 옵션으로 존재한다. 단순 equals 필터는 조용히 누락한다.
4. **빈 값은 "아니오" 가 아니다.** 옛 행은 `명세 구분`·`명세 변경`·`명세 버전`
   이 비어 있다. 필드가 생기기 전에 만들어진 행이라는 뜻이다.
5. **`이동 경로 (삭제 X)` 는 일부러 남긴 리다이렉트다.** 정리하지 않는다.
6. **`설계 문서` 는 integration 에 연결돼 있지 않다.** agent 가 읽어야 하면
   사람이 페이지에서 `... > 연결` 로 추가해야 한다.

## agent 접근 방법

토큰은 저장소의 `.notion.env` 에 있다. CLI 는 `ntn`.

```bash
set -a && . ./.notion.env && set +a
ntn pages get <page-id>
ntn api v1/data_sources/<data-source-id>/query -d '{"page_size":50}'
```

자세한 사용법·필터 예제·쓰기 정책은 저장소 `.agents/docs/NOTION.md` 에 있다.
