**하루에 사람당 한 행.** 제목은 `YY.MM.DD 한 일` (95행 중 93행이 이 형식).
`태그` 가 작성자다.

본문 형식 — agent 가 쓰는 행은 이대로 따른다:

```markdown
# 개요
- 조회(기준: 최근 1일, KST): Jira …건, GitHub PR …건.
- <그날이 무슨 날이었는지 한두 문장>
## PR
- [merged] feat(scenario): … — artel-agent-server#101
- [open]   fix(scenario): … (ARTEL-508) — artel-orchestration-server#163
# 회고
회고 작성 필요
```

기존 행들이 지키는 규칙:

- 근거 범위를 명시한다. 예: `GitHub 근거만으로 작성(Jira 근거 없음, 추측으로 채우지 않음)`.
- PR 은 한 줄에 하나. 상태(`[merged]`/`[open]`/`[closed]`) + conventional commit 제목
  + `repo#번호`.
- **`# 회고` 는 사람이 쓴다.** agent 가 남의 회고를 지어내지 않는다.
- **`작성 완료` 는 사람이 체크한다.** agent 는 `false` 로 둔다.
